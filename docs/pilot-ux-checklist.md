## A. 요양보호사 (장갑 모드)

- [ ] 담당 어르신 그리드에서 대상 선택 ≤ 10초
- [ ] 퀵작성: 사진(선택) → 칩 3개 → 전송 ≤ **2분** (장갑 켠 채 5회)
- [ ] 오늘 미작성 빨간 뱃지/리스트로 마감 전 확인 가능
- [ ] Staff FAB으로 작성 허브 진입
- [ ] 터치 타깃 ≥ 56px (Staff 모드)
- [ ] 오프라인 초안: 로컬 저장 후 재전송 가능 (와이파이 약할 때)

## B. 보호자 (10초 안심)

- [ ] 로그인 홈에서 오늘 사진·상태칩·한줄·식단이 한 화면에 보임
- [ ] 매직링크로 **앱 설치 없이** 소식 열람 ≤ 10초
- [ ] 하트/감사 반응 1탭 완수 (70대 큰글씨 모드 포함)
- [ ] 면회 예약 / 물품 요청 티켓 제출 가능
- [ ] Quiet hours 안내(밤 알림 억제) 이해 가능

## C. 시설장·복지사

- [ ] 가족 연동 승인 ≤ 3탭
- [ ] 공지·식단 1회 작성 → 전체 보호자 공유
- [ ] 소통 리포트(`/reports/stats`) 열람률·발송수 확인 ≤ 3탭
- [ ] 교대 인수인계(내부) 작성·열람, 보호자 메뉴에 노출되지 않음
- [ ] 시설 홈페이지(`/facility/happy-care`) 공지·앨범 연동 확인

## D. 접근성·품질 게이트

- [ ] 큰글씨 모드(프로필)에서 핵심 동선 완주
- [ ] 포커스 링·대비 AA 수준
- [ ] `prefers-reduced-motion` 시 과도한 모션 없음
- [ ] 다크패턴 없음(가짜 긴급 배지·열람 압박 문구 금지)

## E. 파일럿 후 보정 우선순위

1. 작성 시간 > 2분인 단계 제거/칩화
2. 보호자 홈에서 10초 초과 요소 접기
3. 미작성·미열람 정렬이 “비난 UI”가 되지 않게 문구 조정
4. 매직링크 만료·재발송 UX
